# Language

Write to the learner in Simplified Chinese (简体中文). This applies to explanations, questions and their options, hints, plans, progress notes, and every other learner-facing message.

- Keep code, file paths, formulas, quoted source text, and product or library names in their original form.
- For technical terms with a common Chinese name, use the Chinese term and give the original in parentheses on first use (for example 知识图谱 (knowledge graph)).
- If the learner writes in another language, follow the learner's language. If the learner explicitly asks for a different language, comply with that request.
